# FAB 유틸리티 OpenUSD: 설비 라이브러리에서 실규모 연구용 FAB까지

반도체 FAB 유틸리티 설비 라이브러리(Blender)를 ID 기반 OpenUSD 자산으로 옮기고, 그 자산으로 실규모 연구용 FAB를 9단계로 지어 단계마다 규칙으로 검사한 뒤 Omniverse Kit에서 연다. FAB를 짓는 순서를 객체 단위로 기록하는 시공 BIM과, 물리 환경을 고려한 배관 경로 최적화를 하려고 시작했다.

- 기간: 2026-11-05 – 11-18, 개인 프로젝트
- 기술: OpenUSD(usd-core) · Python · NVIDIA Omniverse Kit 110.4.1 · Blender 5.2.2(입력 라이브러리) · Remotion(스냅샷, 영상)
- 규모: 라이브러리 Type 894개를 USD 자산으로, 연구용 FAB에 놓인 객체 30,742개, 모델링 9단계, 입력 저장소 Release 4개 수용
- 값의 성격: 장비 치수와 피난 기준은 연구용 가정이다. RFAB는 연구용 참조 FAB이며 실제 FAB가 아니다. 시뮬레이션 실행, 공학 결과 검증, 현실 데이터 연동은 아직 없다.
- 소스: 비공개다.

## 영상

[fab-openusd-tour.mp4](fab-openusd-tour.mp4): FAB 가이드 투어, 1분 53초, 1280 × 720이다.

연구용 FAB 모델을 사람 눈높이로 걸으며 공간과 설비가 하는 일을 자막으로 설명한다. 전경 → 출입(가우닝실, 에어샤워) → 검사 베이와 웨이퍼 프로버 → 공정 베이(확산·이온주입, 증착·금속 배선, 식각, 포토) → OHT → 장비 반입 → 서브팹 → 유틸리티 별동 → 외관 순서다.

https://github.com/user-attachments/assets/2656e8f6-65c4-4f98-a54a-8cde49a45a18

- 라벨과 미니맵은 USD 모델의 ID와 위치로 그렸다. 프로버 앞에서는 데이터 층을 드러내 모델 값(위치, 크기, 연결 Port, 목표 LOD)과 현장 값(센서 연동 예정)을 나란히 보인다.
- 화면은 Omniverse Kit 실시간 경로 추적으로 찍었다(2026-11-18). 조명은 촬영용으로 더했고, 지붕을 걷은 화면과 재구성 장면(OHT 차량, 장비 반입)은 영상에 표시했다.

## 근거

- 수치: 저장소 기록(G0 실측과 G1 변환기 2026-11-05, G3 1–9단계 검사 2026-11-05 – 11-13, 입력 Release 수용 2026-11-10 – 11-17)
- 화면: Omniverse Kit RTX 캡처(2026-11-18). 2쪽의 Blender 원본 화면과 펌프 속성 창은 2026-11-16 캡처이고, 4쪽 리프트 그림은 입력 저장소 Release의 렌더다.
- 재구성: 반입 경로와 OHT 화면은 재구성이다. 장비를 경로 따라 옮겨 찍었고, OHT 차량은 견본을 캡처할 때만 얹었다.
