# QUANT: Revit 물량 공제 검토 애드인

Revit 구조 모델에서 부재끼리 겹친 콘크리트 체적을 모델링 기준대로 누가 가질지 판정하고, 공제한 뒤의 정미 물량을 내는 애드인입니다. 모델을 고치는 것이 아니라, 고칠 곳과 방법을 보고합니다.

- 개발: [tygwan](https://github.com/tygwan), Claude Code와 함께 만들었습니다(2026.11).
- 기술: C# · Revit API · WebView2(창) · MCP(AI가 Revit을 조작하는 통로)
- 검증: Revit 2026.5에서 시험 케이스 23개에 검사 104개를 돌려 모두 통과했습니다. 검사는 손으로 계산한 기댓값과, 결합을 모두 푼 Revit 체적으로 따로 맞춰 봅니다.
- 소스: 아직 공개하지 않았습니다.

## 스냅샷

[quant-snapshot.pdf](quant-snapshot.pdf)는 16:9 네 쪽입니다.

1. 개발 동기: Revit 결합 순서가 콘크리트 물량을 바꾸는 세 경우와 모델링 기준
2. 구성요소와 데이터 흐름: 모델에서 정미 물량까지 다섯 단계
3. 전과 후: 같은 시험 모델의 Revit 체적과 정미 물량, 실제 창 화면
4. 문제 해결과 개발 방식: 공통 부분을 두 번 빼던 계산을 짚어내고 고친 과정, MCP로 AI가 Revit을 직접 조작하고 Revit을 끄지 않고 새 빌드를 올리는 방식(핫리로드)

## 근거

- 화면과 수치는 2026-11-18 Revit 2026.5 시험 모델 실행 값입니다. 시험 케이스 23개, 부재 46개이고 검사 104개가 모두 통과했습니다. 금액은 시험 단가로 계산했습니다.
- 상자 그림은 시험 케이스의 치수로 다시 그렸습니다.
- 공통 부분 계산을 고친 과정은 2026-11-02 시험 기록이고, 창 멈춤을 고친 과정은 2026-11-09 시험 기록입니다.
