# BIM-space

Revit · Navisworks 실무 자동화 기능과 OpenUSD 작업을 모아 두는 곳이다. 만든 사람은 [tygwan](https://github.com/tygwan)이다. 기능마다 폴더 하나를 두고, 완성된 것부터 올린다.

| 기능 | 내용 | 위치 |
|---|---|---|
| BIM Agent | Navisworks 플랜트 모델 진단 → 부재 연결 관계 → 시공 순서 → TimeLiner 4D. 지금은 포트폴리오만 있고, 소스는 공개 예정이다 | [labs/bim-agent/portfolio](labs/bim-agent/portfolio) |
| FAB 유틸리티 OpenUSD | Blender 설비 라이브러리 → OpenUSD 자산 → 실규모 연구용 FAB 조립과 단계별 규칙 검사 → Omniverse Kit. 지금은 포트폴리오만 있다 | [labs/fab-openusd/portfolio](labs/fab-openusd/portfolio) |
| QUANT | Revit 구조 부재의 결합·겹침 → 부재 우선순위 규칙으로 판정 → 겹친 체적 측정 → 정미 물량과 고칠 곳 보고. 지금은 포트폴리오만 있다 | [labs/quant/portfolio](labs/quant/portfolio) |
